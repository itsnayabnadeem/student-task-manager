# Student Task Management Application

A simple and user-friendly task management application designed to help students organize their daily tasks and manage their academic responsibilities efficiently.

## Overview

Student Task Manager provides a simple interface where students can add tasks by entering a title and description. The project focuses on simplicity, organization, and ease of use.

## Features

- Add new tasks
- Enter a task title
- Add a task description
- Keep tasks organized in one place
- Simple and easy-to-use interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Git and GitHub

## Getting Started

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter a task title and description.
5. Click the **Add Task** button.
